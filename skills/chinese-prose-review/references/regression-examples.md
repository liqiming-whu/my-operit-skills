# 文风审查回归案例

这些是**检验审查器是否会误伤自然中文**的样例；不是要求作者仿写的句式模板。阅读评价与脚本匹配必须分开：脚本可能标出一条好句，不等于该句需要修改。

| 输入片段 | 脚本可提示 | 人工预期 |
|---|---|---|
| “她想要的不是胜利，而是尊严。” | 否定对照候选 | 典型旁白假升华，通常应考虑删解说 |
| “不是这张，是昨天那张。” | 可出现否定对照候选，也可不命中 | 纠正具体事实，保留 |
| “高人住在很远的地方。远到收不着润笔。” | 不应因语义深层而误报 | 保留；不要求解释“很远”的双关 |
| “她没有哭，没有喊冤。她是在证明自己有尊严。” | 后置解说候选 | 删解说通常比增加肢体描写更好 |
| “她笑了。” | 无 | 正常而简洁，保留 |
| “他的指节泛白。” | 套话候选 | 看人物、场景与前文重复程度；不直接判错 |
| “他说话的时候，窗外下起了雨。” | 无 | 正常句式，保留 |
| “我大概明天再来。” | 无 | 角色表达真实不确定性，保留 |
| “她像往常一样，收起书卷。” | 无（或非必改信号） | 自然日常，保留 |
| 连续七句人物对白，没有动作插入 | 结构统计提示 | 不等于“传球式对白”；读是否自然 |
| “她用力将剑插进石缝，指节泛白。” | 套话候选 | 重复动作信息可能需要压缩，但也可能符合紧急场景 |

不可接受的“修改成功”示例：为了消除“她站得很稳”，把站在厨房等早饭的角色改成“脚跟碾紧泥土，腰背绷起”。这比原句更不自然，虽然可能让某个禁词统计归零。

## B01 / D03 工程回归

依据任务提供的历史要点添加，原始清单链接当前不可读。新增测试使用独立构造的通用短句，不读取小说文件。

- B01：保护“她站得很稳”“不禁”“或许”“的时候”、合理否定句、比喻、破折号与连续对白。纠正事实的“不是……而是……”可进入候选索引，但不得判错或自动改写。
- D03：真实 CLI 扫描不新增文件、不改原稿；显式报告只写新路径；符号链接与硬链接输出均拒绝；候选另存不覆盖；CRLF 字节哈希一致；原稿与基线不符时回验失败。

脚本测试只能验证索引和文件边界，不能证明模型未来的文学建议不会误伤。最终仍须完整重读。
