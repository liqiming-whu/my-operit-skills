# 中文小说文风审校 Skill

## 使用时机与边界

只在正文已有可读初稿、用户要求语言审校、或文学修改者接稿后执行。**不得在作者起草前强制列出禁词或遍历规则，不得替作者预先设计每个文学瞬间。**

Skill 的目标不是“检出越多越好”，而是帮助一篇小说变得更自然、更值得读。文学修改应保留原稿的声音和已经成立的好句，避免把生动文字改成书面官样文章。

**默认只做诊断，不修改原文。** 若用户明确要求编辑，另存修订候选并给出有代表性的前后对照；不覆盖原稿。

## 审查原则（必须遵守）

1. **信任已经成立的文学瞬间。** 一句对白、一个动作、一个细节已经让读者理解时，不在后面补说明其意义的旁白。不要因为找不到解释句，就反过来强迫作者制造留白。
2. 区分**明确陈词滥调**、**语境可疑的句式**、**合理的文学选择**。相同字词的出现不等于同样的缺陷。
3. **DO NOT** optimize for the number of flags. A recommendation MUST explain the concrete reading problem caused by the passage, not merely cite a banned token.
4. **DO NOT** replace ordinary Chinese with elaborate poetic metaphors, complex body movements, clinical terminology, or deliberately inverted syntax.
5. **MUST NOT** rewrite the author's strongest lines just to make the entire chapter sound uniform. Preserve vivid irregularity where it serves the scene.
6. 事实、视角和人物事件硬伤，交给独立审计岗位处理；本 Skill 可标出明显疑点，但不要以“文风审查”之名私自更改设定。
7. 不为每个问题都给出改写方案。许多问题可以简单通过删除重复解释解决；也有些地方无需修改。

## 审校次序

### 第一遍：连续阅读

先通读整段或整章，不标注每个可疑词。回答：哪些地方读起来自然？哪里开始感到用力、卡顿、单调或说教？有没有必须保留的独特表达？**先保护成功的段落，再考虑修错。**

### 第二遍：识别八股与模板

下列模式是重点；表中标明审查强度：

| 类型 | 典型文本 | 审查与修订原则 |
|---|---|---|
| 强禁：假升华式否定转折 | “她要的不是胜利，而是尊严”“没有悲伤，只有……” | 叙述者直接给主题下结论时应重写。若是人物确实纠正具体事实的口语“不是……而是……”，不得机械判错 |
| 强禁：默认情绪动作 | “指节泛白”“脸色泛白”“喉结滚了滚”“眼神闪了闪”“嘴角勾起一抹弧度”“笑意不达眼底” | 提示作者重新选择该人物特有的反应，不作逐词同义替换 |
| 强禁：动作后配解说 | “她没有哭，没有喊冤，她是在……” “这个动作显出她的……” | 若对白或动作已经足够，优先删掉旁白解说 |
| 高风险：否定兜底 | “眼睛亮得有内容，不是应酬式的兴奋” | 若只是补充排除一个读者根本不会想到的判断，删除；必要的否定事实可以保留 |
| 高风险：公式化心理 | “某种情绪在心底蔓延”“她的笑里藏着多年……” | 让具体心理、选择和感知直接发生，不把抽象情绪塞入身体局部 |
| 高风险：习惯性类比 | “像是在……” “仿佛……” “像……的……” | 不是禁绝比喻；判断意象是否新鲜准确，是否出自人物感知，是否只是多说一遍 |
| 高风险：无意义的具体数字 | “劈柴八万斤、挑水三千石” | 精确数据有证据功能时保留；以统计表证明品格、记忆或勤奋时，改为生活经验与可见行为 |
| 高风险：译腔与过密修饰 | “她产生了想要离开的意图” “他抬起他的手” “xx的、xx的、xx的” | 依中文自然语序重构，不制造无端的典雅词汇 |
| 高风险：短句/问答机械推进 | “为何？”“不知。”“可有？”“没有。”连续过密 | 判断对话是否真正属于人物，是否变成办案记录；允许场景需要的简短问答 |
| 高风险：三段重复解释 | 概念 → “这种XX” → “是同一回事” | 不要三次宣布同一判断，选最准确的一次表达 |
| 高风险：过分花哨的动作/声音 | “喉咙闷出一声笑”“肩头微微一颤”反复出现 | 平常的笑就写“笑了”；情绪不是每次都需身体特写 |
| 语境判断：朴素词语 | “平、稳、松、通、绕、躲”“很”“是”“比”“一缕”“三个字” | **不得逐字禁用。** 它们是正常汉语、数字和情节事实可能必需的表达 |
| 语境判断：标点与风格 | 破折号、省略号、自由间接引语、复合长句 | 判断是否影响节奏或清晰度；不得因为某种标点本身存在就报错 |

### 第三遍：节奏、心理和读者空间

- 检查是否过多强调“人物很聪明/很温柔/很委屈/很懂事”，或让旁观者反复惊叹替作者作证。
- 检查作者是否让每句对白必须推进剧情、每个场景必须出金句、每个动作都必须有深意。
- 检查心理是否真正属于视角人物，是否在关键处自然出现、在不必要处安静退下。
- 检查人物关系是否通过不同的说话习惯、共享生活与分歧显现，而不只是反复提供证明亲密的动作。
- 检查是否因反八股而走到另一个极端：过度删“很/是”、生硬倒装、冗余诗化替换、莫名其妙的悲苦回忆。
- **好句无需文学解说。** 如果删去解释之后意思仍然明白，优先让句子自己站住。

## 输出格式

默认简洁输出，不打带小数点的文学分数，不按出现次数算总成绩。

1. **优先保留的东西**：指出1—3处具体成功的对白、动作或意象，以及为何在这一场成立。
2. **最影响阅读的地方**：按严重程度列最多5项，附原句、上下文及阅读效果；区分「明确模板」「语境问题」「主观审美」。
3. **最小改动建议**：提出删除、压缩、局部重写或保持原样的具体建议；必须说明会失去什么。
4. **若获授权修改**：另存候选版本，附关键处的前后对照，不覆盖既有原稿。并以整章阅读效果为最终判断。
