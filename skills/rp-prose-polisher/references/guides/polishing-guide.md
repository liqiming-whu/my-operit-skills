# 深度润色指南：去除AI痕迹

当正文需要进行深度润色时，必须执行以下润色流程。核心目标：**让文字读起来像人写的，而不是AI生成的。**

AI文字的特征是：华丽但空洞、流畅但无个性、正确但无趣。润色就是把这些特征逐一打破。

---

## 润色前的诊断

### AI味的七种典型症状

| 症状 | 特征 | 典型表现 |
|------|------|---------|
| 形容词堆砌 | 一句话塞入多个华丽修饰词 | "璀璨的星辰在浩瀚无垠的夜空中闪耀着瑰丽的光芒" |
| 抽象陈述 | 直接告诉读者情绪，而不是展示 | "他感到一阵复杂的情绪涌上心头" |
| 四字格律轰炸 | 连续使用多个成语/四字词 | "他心潮澎湃、热血沸腾、百感交集" |
| 对话无个性 | 所有角色说话方式一样 | 每个人都用完整的句子、礼貌的措辞、不出错 |
| 节奏单一 | 全篇长句或全篇短句，没有变化 | 每句都是30字以上的复合句 |
| 描述笼统 | 用大词概括细节 | "房间很温馨"、"她很漂亮" |
| AI句式模板 | 使用AI高频套话 | "仿佛……一般"、"不禁……"、"某种……的存在" |

> 注：诊断表中的「对话无个性」属于去AI味的整体目标，通过润色流程中的整体打磨覆盖，不设独立编号规则。

### 防过度润色原则

以下做法均属过度润色，必须避免：

- ❌ 为改而改：把原本自然的表达硬改成奇怪的句式
- ❌ 去修饰=去描写：把所有的形容词删光，变成白开水
- ❌ 口语化=随便写：把对话改成毫无信息量的口水话
- ❌ 长短交替=机械交替：长短长、短长短地数着字数改

**判断标准：改完之后大声读一遍。如果读起来别扭、不顺口，说明改坏了。**

## 规则一：形容词大清洗

### 需要警惕的AI高频修饰词

**视觉类**：璀璨、瑰丽、绚烂、斑斓、流光溢彩、美轮美奂、金碧辉煌
**气势类**：磅礴、浩瀚、无垠、无边、恢弘、气吞山河、波澜壮阔
**程度类**：无比、极其、非常、格外、分外、难以言喻的
**氛围类**：静谧、幽深、诡谲、肃穆、凝重

### 清洗方法

1. **删**——直接删掉不增加信息量的形容词
2. **换**——把抽象的华丽词换成具象的细节
3. **限**——每段最多保留两个修饰性形容词

### 规则一（续）：比喻修辞密度控制

**需要警惕的比喻标记词**：

| 类别 | 标记词 |
|------|--------|
| 明喻前缀 | 仿佛、似乎、如同、宛如、犹如、好似、恰似、好比 |
| 像…一样 | 像…一样、像…似的、就像…一样 |
| …般的 | …般的、…般地 |
| …似的 | …似的（独立用法，如"发疯似的""着了魔似的"） |

**清理方法**：
1. 量化上限：脚本检测阈值 ≤ 0.5 处/千字
2. 删：比喻只是修饰、删掉不影响表达的，直接去掉
3. 换：把比喻替换为具象白描
4. 限：每千字保留最多 0.5 个真正必要的比喻

## 规则二：抽象变具象

### 六类常见抽象陈述及替换策略

| 抽象陈述 | 替换策略 |
|---------|---------|
| "他很愤怒" | 写身体反应：拳头攥紧、牙关咬合、呼吸变粗、视线变窄 |
| "她很悲伤" | 写行为异常：没发觉茶凉了、把钥匙放进了冰箱、对平时喜欢的东西毫无反应 |
| "气氛紧张" | 写环境映射：钟摆声突然变大了、所有人都回避对视、有人反复折叠一张纸 |
| "他爱上了她" | 写注意力的倾斜：开始记住她的细节、在意她对自己的看法、对和她有关的信息过度反应 |
| "内心挣扎" | 写矛盾的微行为：手伸出去又收回来、一句话说一半换成了另一句、在两个选择之间反复切换 |
| "感到恐惧" | 写感知变化：时间变慢、视野收缩、听觉变敏锐、身体失控（发抖/僵硬） |

## 规则三：打破四字格律

### 重点打击的AI高频四字词

- **情绪类**：心潮澎湃、热血沸腾、百感交集、思绪万千、感慨万千、情不自禁、不由自主
- **意志类**：毫不犹豫、毫不留情、毅然决然、义无反顾、坚定不移
- **评价类**：无可挑剔、无与伦比、叹为观止、前所未有
- **氛围类**：鸦雀无声、万籁俱寂、灯火阑珊、华灯初上

### 替换方法

1. **展开**——把四字成语展开成具体的画面或动作
2. **删掉**——很多四字词在句中只是填充物
3. **只留一个**——如果实在需要一个成语来定调，只用一

---

## 规则四：节奏感重塑

### 五种节奏调整手法

1. **短句爆破**：在长段落中突然插入一个3-5字的短句，制造冲击
2. **长句流淌**：在连续短句后接一个从容的长句，让读者喘口气
3. **碎片化**：用破碎的句子模拟角色的混乱状态
4. **重复变奏**：有意重复某个词或句式，但每次重复都推进一点
5. **空白停顿**：用段落分隔来制造停顿

---

## 规则五：细节具象化

### 核心方法

**不写结论，写证据。** 让读者看完你写的证据后，自己得出结论。

### 常见笼统词及具象化方向

| 笼统词 | 具象化方向 |
|--------|-----------|
| 温馨 | 温度（暖气/壁炉）、光线（暖黄/台灯）、物品（毛毯/半杯热茶）、声音（钟摆/翻书） |
| 漂亮 | 一个具体的、不完美的特征（嘴唇左边比右边略高、笑起来眼睛先弯嘴角才跟上） |
| 疲惫 | 异常行为（把手机放进冰箱、对平时喜欢的东西没反应、反复看同一行字） |
| 富有 | 不在意的细节（雨伞架里有五把长柄伞、洗手间的擦手巾叠成三角形、冰箱里的水果按颜色排列） |
| 恐怖 | 正常中的不正常（电视机开着但没声音、鱼缸里的鱼全部浮在水面、走廊的灯在闪但频率不对） |

## 规则六：AI句式模板大扫除

### 高频AI句式黑名单

| 句式模板 | 替换方案 |
|---------|---------|
| "仿佛/似乎……一般/似的" | 删掉"仿佛"，直接写比喻；或干脆删掉整个比喻，换一个具体的细节 |
| "不禁……" | 写具体的动作替代"不禁"，或者直接写后面的内容。⚠️ 脚本检测已完全移至规则七·第三类（心理副词）。规则六润色阶段人工尝试替换即可，量化反馈由步骤8 check_cliche.py 提供，不通过时再回头集中处理 |
| "一股……涌上心头" | 写身体反应或具体行为 |
| "内心深处" | 写外在表现让读者推测内心 |
| "在这一刻" | 删掉，直接叙述事件 |
| "某种……的存在" | 具体化那个"某种" |
| "显得格外……" | 删掉，或者换具体的对比 |

## 规则七：AI八股文禁令

### 第一类：标点符号滥用

**破折号（——）**：AI酷爱用破折号做插入说明和语气转折。密度 > 4处/千字需逐一排查，大部分可换成句号或逗号。保留的破折号仅用于真正的语义转折或强调。

### 第二类：总结/概括性套话

| 禁令词 | 替换 |
|--------|------|
| 总而言之 | 删掉，直接写结论；或用更自然的"所以""一句话" |
| 综上所述 | 删掉，小说不需要这种学术措辞 |
| 从某种意义上说 | 删掉，直接说 |

### 第三类：心理/行为副词

| 禁令词 | 替换 |
|--------|------|
| 不禁 | 删掉，直接写后面的动作；或写身体反应代替 |
| 不由地 | 同上 |
| 下意识地 | 只写动作本身，让读者判断是否有意识 |

⚠️ 这些词在**对话中**可以使用（角色口语中"我不禁笑了""他下意识地退了半步"是自然的），但在**叙述和内心描写中**是AI味的典型来源。脚本检测时会自动跳过对话引号内的匹配。

### 第四类：模糊限定词

| 禁令词 | 替换 |
|--------|------|
| 或许 | 删掉，或保留不确定性但换表达方式 |
| 也许 | 同上 |
| 大概 | 同上 |

⚠️ 这些词在**对话中**可以使用（角色口语中"或许吧""大概是这样"是自然的），但在**叙述中**是AI味回避决断的典型表现。脚本检测时会自动跳过对话引号内的匹配。

### 第五类："不是……而是/是……"句式

**禁令句式**：不是……而是…… / 这不是……这是…… / 不是……是……

**替换方法**：把"不是A而是B"拆成两个独立的陈述，或直接删掉"不是A"只保留B。

### 第六类：第一人称心理陈述

| 禁令词 | 说明 | 替换 |
|--------|------|------|
| 我感到 | 直接告诉读者情绪 | 写身体反应或行为 |
| 我觉得 | AI人物的思维标签 | 删掉，直接写想法内容 |
| 我认为 | 同上，更正式 | 同上 |

⚠️ 这些词在**对话中**可以使用，但在**叙述和内心描写中**是AI味的典型来源。

### 第七类：二元对立套话

| 禁令句式 | 替换 |
|---------|------|
| 一方面……另一方面…… | 删掉结构词，用具体内容直接表达矛盾 |
| 说实话…… | 删掉，直接说后面的话 |
| 不过说真的…… | 同上 |
| 不过有一说一…… | 同上 |
| 有一说一…… | 同上 |
| 话说回来…… | 删掉，用段落分隔或直接转折 |

⚠️ "说实话""不过说真的""不过有一说一""有一说一""话说回来""一方面……另一方面……"在叙述和对话中统一视为八股套话，不区分豁免。脚本检测时不再跳过对话引号内的匹配。

### 第八类：时间状语"……的时候"精简

**禁令词**：的时候

**替换策略**（按优先级）：
1. **简化为"时"**：将"……的时候"替换为"……时"（"吃饭的时候"→"吃饭时"）
2. **改为具体动作描写**：将时间状语改为更生动的表达（"她笑的时候"→"她一笑，眼角就泛起细纹"）
3. **重写句子结构**：消除时间状语，用并列短句替代（"当他推开门的时候，雨已经停了"→"他推开门。雨停了。"）

⚠️ "的时候"在**对话中**可以使用（角色口语中的"那时候""小的时候"等是自然的），但在**叙述中**是AI味的常见来源——AI倾向于用"当……的时候"来组织时间关系。润色时必须保证替换后句子连贯自然，严禁粗暴删除。脚本检测时自动跳过对话引号内的匹配。

## 润色执行流程

### 第一轮：结构性润色（对应 SKILL.md 步骤 4.1）

1. 扫读全章——标记所有"不顺"或"不像人话"的地方
2. 执行规则一（形容词大清洗 + 比喻修辞密度控制）
   - 形容词大清洗：删、换、限，每段≤2个华丽形容词
   - 比喻修辞密度控制：搜索比喻标记词（仿佛/似乎/如同/宛如/像…一样/…般的等），删/换/限至≤0.5处/千字。详见下方「规则一（续）：比喻修辞密度控制」
3. 执行规则二（抽象变具象）——逐段检查直接陈述情绪的句子，全部转换
4. 执行规则三（打破四字格律）——搜索连续四字词，打破或删除
5. 执行规则六（AI句式扫除）——搜索黑名单句式，逐一替换

### 第二轮：人物声音润色（对应 SKILL.md 步骤 4.2）

6. 执行规则五（细节具象化）——找出所有笼统描述，替换为具体证据。⚠️ 脚本仅检测16个固定短语（4类形容词 × 4个程度副词），主要靠人工。

### 第三轮：节奏润色（对应 SKILL.md 步骤 4.3）

7. 执行规则四（节奏感重塑）——检查段落长度分布，调整长短句比例。⚠️ 此规则无脚本检测，必须通过朗读检查。
8. 朗读检查——大声朗读全章，读不下去的地方继续改

### 规则七独立执行（对应 SKILL.md 步骤 5）

逐类检查：总结套话 → 心理副词 → 模糊限定词 → "不是…而是…"句式 → 第一人称心理陈述 → 二元对立套话 → 时间状语精简。每类通过后再进入下一类，完成后二次扫读确认无漏网之鱼。（破折号已由 SKILL.md 破折号预处理环节在步骤 2 之后批量处理，此处跳过。）

> 💡 破折号已在步骤 2 之后的预处理中通过 `sed` 批量替换为逗号。若 `check_cliche.py` 在步骤 8 中破折号仍未通过，回到预处理环节二次处理。详见 SKILL.md 破折号预处理。

### 脚本验证（对应 SKILL.md 步骤 7 / 8）

```bash
# 步骤 7
python scripts/check_ai_flavor.py <章节文件路径>
# 步骤 8
python scripts/check_cliche.py <章节文件路径>
```

- 如不通过，根据脚本输出的具体行号和问题类型，回到对应规则重新润色
- 重试机制：同 SKILL.md「🔒 脚本验证通用规则」——每轮降幅 ≥ 动态阈值；连续2轮不降或3轮耗尽则中断询问用户（跳过 / 继续修改）。详细中断流程见 SKILL.md

> **终验回检（对应 SKILL.md 步骤 9）**：步骤 8 后再次运行 `check_ai_flavor.py`，确保八股文修正未引入新的AI语言痕迹。若回验达标（≤ 1.0/千字）则直接通过；若超标则触发单轮定点修复后再次回验。最终回验得分作为文章AI痕迹的最终判定依据。详细步骤见 SKILL.md 步骤 9。
